# Public design-guide instructions

This repository contains public design patterns only.

- Do not add credentials, private URLs, unpublished course or exam content, prompts,
  production traces, or internal identifiers.
- Keep claims about production, learners, customers, adoption, and model quality
  tied to evidence that the public repository actually contains.
- Preserve the distinction between a recommendation and human approval.
- Explain what each pattern proves and what it does not prove.
- Keep implementation-specific details in the linked implementation repository.
- Record a non-obvious design choice as: Decided, Instead of, Why, Costs if wrong,
  and Decided by.
